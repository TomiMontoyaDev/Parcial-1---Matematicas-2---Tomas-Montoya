Regla de Simpson

En vez de aproximar con líneas rectas (trapecios), Simpson ajusta una parábola a cada par de subintervalos. Como una parábola necesita 3 puntos para definirse, n debe ser par — de ahí que la fórmula agrupe los índices impares (coeficiente 4) y los pares (coeficiente 2) de forma distinta.

S_n = \frac{\Delta x}{3}\Big[f(x_0) + 4\!\!\sum_{i\ impar}\!\! f(x_i) + 2\!\!\sum_{i\ par}\!\! f(x_i) + f(x_n)\Big], \quad n \text{ par}

Ejemplos resueltos paso a paso

Ejemplo 1 — Aproximar ∫₀² x² dx usando Simpson con n = 4

1
Verificar que n es par y calcular Δx
n=4 \text{ (par ✓)}, \qquad \Delta x = \dfrac{2-0}{4} = 0.5
2
Evaluar f en los 5 puntos
f(0){=}0,\ f(0.5){=}0.25,\ f(1){=}1,\ f(1.5){=}2.25,\ f(2){=}4
3
Aplicar la fórmula: índices impares ×4, pares (interiores) ×2
S_4 = \dfrac{0.5}{3}\big[0 + 4(0.25+2.25) + 2(1) + 4\big] = \dfrac{0.5}{3}[0+10+2+4] = 2.\overline{6}
Valor exacto: 8/3 = 2.667 — Simpson da el valor exacto porque x² es polinomio de grado ≤ 3

Ejemplo 2 — Aproximar ∫₀^π sin(x) dx usando S₄

1
n = 4 es par, calcular Δx
\Delta x = \dfrac{\pi - 0}{4} \approx 0.7854
2
Evaluar seno en los 5 puntos
f(0){=}0,\ f(0.785){\approx}0.707,\ f(1.571){=}1,\ f(2.356){\approx}0.707,\ f(3.1416){\approx}0
3
Aplicar la fórmula de Simpson
S_4 = \dfrac{0.7854}{3}\big[0 + 4(0.707+0.707) + 2(1) + 0\big] \approx 2.0045
Valor exacto: 2 → error ≈ 0.0045, notablemente mejor que L₄, R₄, M₄ o T₄ con el mismo n
