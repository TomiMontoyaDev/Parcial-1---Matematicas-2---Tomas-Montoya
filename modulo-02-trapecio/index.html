Regla del Trapecio

En vez de aproximar cada franja con un rectángulo, la unimos con una línea recta entre f(x₀) y f(x₁) — formando un trapecio. Geométricamente, esto corrige el error sistemático de Lₙ y Rₙ: donde uno sobreestima, el otro subestima, y el trapecio promedia ambos.

T_n = \frac{\Delta x}{2}\Big[f(x_0) + 2\sum_{i=1}^{n-1} f(x_i) + f(x_n)\Big], \qquad \Delta x = \frac{b-a}{n}

Justificación geométrica: el área de cada trapecio es (f(x₀)+f(x₁))/2 · Δx — el promedio de las dos alturas por la base. Al sumar todos los trapecios, cada punto interior se cuenta dos veces (una como extremo derecho del anterior, otra como extremo izquierdo del siguiente), de ahí el factor 2 en la fórmula.

Ejemplos resueltos paso a paso

Ejemplo 1 — Aproximar ∫₀² x² dx usando la regla del trapecio con n = 4

1
Ancho de cada trapecio
\Delta x = \dfrac{2-0}{4} = 0.5
2
Evaluar f en los 5 puntos de la partición
f(0)=0,\ f(0.5)=0.25,\ f(1)=1,\ f(1.5)=2.25,\ f(2)=4
3
Aplicar la fórmula — extremos sin duplicar, interiores × 2
T_4 = \dfrac{0.5}{2}\big[0 + 2(0.25+1+2.25) + 4\big] = 0.25[0+7+4] = 2.75
Valor exacto: ∫₀² x² dx = 8/3 ≈ 2.667 → error ≈ 0.083

Ejemplo 2 — Usar T₅ para aproximar ∫₁³ (1/x) dx

1
Ancho de cada trapecio
\Delta x = \dfrac{3-1}{5} = 0.4
2
Evaluar f(x) = 1/x en los 6 puntos
x_0{=}1,\ x_1{=}1.4,\ x_2{=}1.8,\ x_3{=}2.2,\ x_4{=}2.6,\ x_5{=}3
3
Sumar extremos + 2×interiores
T_5 = \dfrac{0.4}{2}\Big[1 + 2\big(\tfrac{1}{1.4}+\tfrac{1}{1.8}+\tfrac{1}{2.2}+\tfrac{1}{2.6}\big) + \tfrac{1}{3}\Big] \approx 1.1121
Valor exacto: ln(3) ≈ 1.0986 → como 1/x es cóncava hacia arriba, el trapecio siempre sobreestima
